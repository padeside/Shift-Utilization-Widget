# Shift-Utilization-Widget
Auto-update hosting for the Shift Utilization Widget Firefox extension


This repository hosts the update manifest and signed extension files 
for the Shift Utilization Widget Firefox browser extension.

## What this repo contains

- `updates.json` — Firefox update manifest
- `shift-widget-*.xpi` — Signed extension releases

## About the extension

Shift Utilization Widget is a Firefox extension for data center 
technicians to track shift time and log work activities directly 
from the browser.
